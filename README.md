# Castix AMOLED Community

Official web frontend: https://castix.siwane.xyz/

Browse public information in a browser; open @Castix_bot for authenticated theme browsing, submissions and downloads.

Deploy repository root through GitHub Pages with the supplied CNAME. Keep config.js API endpoints unchanged. 

Privacy requests are handled manually through community moderators.

## Advertising

Advertising is disabled in this release. The optional Monetag (Telegram Mini Apps SDK) integration lives in ads.js; it does not load its SDK or request ads while CASTIX_ADS_ENABLED is false in config.js, and never runs on the public website. Enable only after approval and integration testing. Google advertising is disabled.
